# LMS Parser

Скрипт для автоматического парсинга вопросов из системы управления обучением (LMS) MIPT.

## Описание

Этот скрипт выполняет вход в систему LMS, загружает страницы теста и парсит вопросы двух типов:
- **Вопросы с выбором ответа** (multiple choice) — один или несколько вариантов
- **Вопросы на сопоставление** (matching) — таблица с утверждениями и вариантами ответов

## Требования

- Python 3.x
- Библиотеки:
  - `requests`
  - `beautifulsoup4`
  - `urllib3`

Установите зависимости командой:

```bash
pip install requests beautifulsoup4 urllib3
```

## Настройка

Перед запуском отредактируйте файл `lms.py` и укажите следующие параметры:

```python
USERNAME = "ваш_логин"      # Ваш логин в LMS
PASSWORD = "ваш_пароль"     # Ваш пароль в LMS

ATTEMPT_ID = "id_попытки"   # ID попытки прохождения теста
CMID = "id_курса"           # ID модуля курса
TOTAL_PAGES = 25            # Количество страниц с вопросами
```

### Как найти параметры теста

1. Откройте тест в браузере
2. В адресной строке найдите параметры `attempt` и `cmid` в URL
3. Скопируйте их значения в соответствующие переменные

## Запуск

```bash
python lms.py
```

## Вывод

Скрипт выводит в консоль:
- Номер вопроса
- Тип вопроса (выбор ответа / сопоставление)
- Текст вопроса
- Варианты ответов (для вопросов с выбором)
- Утверждения и доступные варианты (для вопросов на сопоставление)

## Примечания

- Скрипт отключает проверку SSL-сертификатов (может потребоваться для внутренних систем)
- Между запросами добавлена пауза 0.5 секунды для снижения нагрузки на сервер
- Для работы необходимы действительные учётные данные в системе LMS
